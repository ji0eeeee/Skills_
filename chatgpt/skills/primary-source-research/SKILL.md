---
name: primary-source-research
description: Investigate a question against high-trust primary sources and capture cited findings as a Markdown file in the repository. Use for focused documentation or API research; do not use for the existing structured research-outline workflow.
---

Use a background subagent for the reading legwork when delegation is available and allowed, so other useful work can continue in parallel. Otherwise perform the research directly.

The research must:

1. Prefer primary sources such as official documentation, source code, specifications, and first-party APIs. Trace every material claim to the source that owns it.
2. Produce one concise Markdown file with citations placed next to the claims they support.
3. Save the file where the repository already keeps research notes. Match the existing convention; if none exists, choose a sensible repository-local location and report it.

Do not overwrite an existing research artifact unless the user asked for an update.
